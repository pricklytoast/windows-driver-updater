Scans your PC for outdated or missing drivers and downloads the latest official versions. Covers GPU, audio, network, USB, and chipset drivers — no third-party bundles or bloat.

## Features

- Detects outdated drivers across all device categories
- Downloads official driver packages from manufacturer sources
- One-click update for all outdated drivers at once
- Creates a system restore point before each driver install
- Shows driver version changelog before installing

## FAQ

**Is it safe to update all drivers at once?**  
It's generally safe. A restore point is created before each install so you can roll back if anything breaks.

**Does it include NVIDIA and AMD GPU drivers?**  
Yes — it detects the installed GPU and downloads the latest WHQL-certified driver from NVIDIA or AMD directly.
